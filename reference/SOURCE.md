# Reference provenance

The target/dependency manifest in this project was derived from the supplied `Tool-Tree-main` addon:

`.github/addon/patch_rom/index.bash`

The reference implementation of the actual ROM bytecode patch operations is an Android AArch64 ELF:

`.github/addon/patch_rom/patch-rom`

The new project intentionally does not reproduce undocumented bytecode changes as invented Python substitutions.
